# E36731A LAN Control v0.5.0

Windows 10/11 x64 免安裝 EXE＋本機 HTML，以 LAN / TCP 5025 控制 E36731A。預設 IP **169.254.30.1**，不需安裝 Python、Go 或 VISA。

[下載 Windows v0.5.0](https://github.com/Oloid666/E36731A-LAN-Control/raw/refs/heads/main/downloads/E36731A-LAN-Windows-x64-v0.5.0.zip)

**本版已移除低速軟體 ESR；尚未完成原生硬體 ESR 控制。** Battery 現為原廠 PS2Q 固定電壓模式，不會依量測電流調壓。ESR 欄位顯示「尚未設定」，0／10／100 mΩ 按鈕停用；程式不宣稱儀器內阻為零。

## v0.5.0 操作簡化與取消修正

- 主畫面預設電池 PS2Q CV；Source／Sink 與保護設定移至摺疊進階區。舊 Source／Sink 偏好載入時改為電池模式，保留仍有效的數值；無效時回到預設並記錄。這只改表單，不自動設定儀器。
- 開啟帶有有效本機工作階段的頁面，自動嘗試連線一次。只識別與讀取，不改模式／設定，不會 ON；失敗後不在背景反覆連線，可按一鍵套用重試。
- 「一鍵套用電池設定」依序連線（需要時）、確認 OFF、設定 PS2Q 與參數、讀回驗證；完成仍為 OFF。已 ON 時按套用會先 OFF。
- 正常 OFF 取消不再誤當通訊故障而斷線；讀取逾時或不完整回覆仍採故障處理，避免把舊回覆冒充 OFF。
- SCPI 操作中，狀態端點以獨立快照回覆，顯示正在執行的步驟與命令。表單／快速鍵可編輯下一組草稿；只禁止同時送出第二次套用／ON。送出的參數固定使用按下當時的快照，不會被後續編輯改動。
- 一般 OFF 保留已驗證設定；可直接再 ON，但 ON 前仍重新讀回驗證。表單變更或取消未完成的設定後，須重新套用。失敗／斷線會清除驗證狀態。
- 加入 V ＋／−：1／10／100 mV 步距，電池模式限制在設定的上下界內；只改草稿，需按套用。這不是硬體電壓斜率或輸出 ON 時即時調壓。
- 保留 SCPI 最後 80 行複製與剪貼簿拒絕時的 Ctrl+C 備援。

## ESR 與控制功能狀態

- 刪除 I×R 電壓回授、5 mV／輪調壓及離線模型預覽。
- 保留 PS2Q、固定電壓／電流設定、OVP、模式與讀回驗證。新 SCPI 錯誤或讀回不符會停止；不支援 PS2Q 不會改用 PSUP/LOAD 交替冒充雙向。
- 非零 ESR 或舊軟體 ESR 模式請求會在送出儀器指令前拒絕，沒有軟體替代路徑。舊設定載入時轉成 PS2Q CV／不請求內阻，保留電壓等參數並寫入遷移紀錄，不自動設定或 ON。
- SCPI 通訊紀錄增加「複製最後一段（80 行）」；只複製當時畫面已收到的紀錄，不發送儀器指令。服務失聯後仍可複製；剪貼簿被拒絕時顯示已選取文字，按 Ctrl+C。
- 保留電池及 Io 快速設定、偏好保存、唯讀診斷、毫秒紀錄、JSON／CSV 匯出。

## 原生 ESR 卡在哪裡

規格表列有可程控輸出電阻，但目前核對的 Programming Guide 沒有找到對應的 PS2Q 硬體串聯電阻設定、啟用與讀回命令。`RES` 明確是電子負載 CR 輸入電阻。原廠雙象限能力也不能直接當作硬體 ESR 能力。

因此本版**無法滿足固定 10 mΩ、由硬體即時處理雙向 ESR 的要求**。這不是已證明儀器不能做，而是缺少可驗證的控制介面與模式適用證據。原廠依據、精確待確認問題與後續實作方式見 [NATIVE_ESR_STATUS.md](NATIVE_ESR_STATUS.md)。沒有使用其他型號或猜測的 ESR 指令。

## 操作

1. 面板確認現場狀態、關閉舊 EXE，將新版 ZIP 解壓縮到獨立資料夾，再啟動 EXE。保留程式視窗。
2. 頁面自動連線至儲存 IP（預設 169.254.30.1）；不會自動套用或 ON。主畫面模式預設為電池 PS2Q。
3. 選 1S／2S／3S／4S、Io，或調整 V。按「一鍵套用電池設定」，程式會先 OFF 再設定並讀回。操作期間顯示步驟，不需因按鈕暫停而反覆點擊；OFF 可取消。
4. 完成後按 ON；平常 OFF 後可再 ON。若編輯過表單，先重新套用。
5. 「保護與進階模式」可改 OVP／軟體界線／Source／Sink；「連線進階／除錯」提供唯讀診斷、斷線與匯出。
6. 出錯按「複製最後一段（80 行）」或匯出 JSON；OFF 未確認時用面板確認。結束用「OFF 並結束程式」。

PS2Q 的實際 Source/Sink 運作、電流符號、Sink 硬體限流及動態行為，尚待現場實機驗證。`CURR` 是儀器電流設定，**不能據此宣稱已設定獨立硬體 Sink 限流**；本程式的雙向電流／電壓監控是低速軟體停止機制，不能取代硬體保護。

## 快速設定

| 電池鍵 | 設定電壓 | 上限／滿電 | OVP | 軟體監控下限 |
|---|---:|---:|---:|---:|
| 1S | 3.7 V | 4.2 V | 4.3 V | 3.5 V |
| 2S | 7.4 V | 8.4 V | 8.6 V | 7.0 V |
| 3S | 11.1 V | 12.6 V | 12.9 V | 10.5 V |
| 4S | 14.8 V | 16.8 V | 17.2 V | 14.0 V |

電池鍵適用 Source／Battery；Io 為 1／2／4／8 A，CR 不作用。按鈕只帶入草稿，不自動設定或 ON；輸出 ON 或忙碌時仍可編輯下一組，套用時會先 OFF。為一般鋰離子電池預設，並非所有化學體系與 DUT 的建議額定值。

## Source／Sink 與阻值

Source 設定 V 與電流上限，實際 CC/CV 由負載與限制決定，選單僅設定 ON/OFF 偏好。Sink 支援 CC、CV、CR。`FUNC RES`／`RES`／`RES?` 是 CR 負載阻值，0.08–4000 Ω，依 V/R 吸收電流，**不是電池 ESR**。

應用限制 30 V／20 A／200 W，不是儀器完整規格。原生 ESR、獨立 OCP 操作與電壓升降斜率介面尚未整合；不宣稱本版已完成這些功能。

## 量測、紀錄與失效

V、I 依序量測，功率是 V×I 計算值，不是同步高速取樣或儀器平均功率。不傳送已在現場造成逾時的 `MEAS:POW?`。曲線／CSV 保留最近 120 筆；SCPI 畫面與 JSON 保留最近 2000 行。

網頁超過 10 秒未回報會嘗試 OFF 並斷線；背景分頁節流可能觸發。強制結束 EXE、斷網、當機或關機無法保證 OFF。OFF 不是物理隔離。通訊不完整時不拿舊回覆冒充 OFF 確認。

偏好與磁碟紀錄位於 `%APPDATA%\E36731A-LAN-Control\`。儲存只帶入表單；重新開啟頁面自動連線一次，不自動設定或恢復 ON。除錯／複製紀錄包含儀器識別、IP 與參數，分享前可檢查；不含本機工作階段密鑰。

本程式只監聽 127.0.0.1，不是雲端直接控制內網。EXE 未簽章，公司可能需要 IT 審核。

## 驗證與原始碼

56 項 Go 測試、race 檢查、go vet 及 JavaScript 邏輯測試通過，Windows x64 已交叉編譯。已以 Linux Chromium 與模擬 API 檢查操作流程及桌面／窄螢幕版面；尚未完成 Windows／實機驗證。替身測試不代表硬體功能、保護時序或動態性能已驗證。

原始碼位於 [src](src)，僅使用 Go 標準函式庫；一般使用者不需要開發環境。

```sh
cd src
go test -race ./...
go vet ./...
node ui_test.cjs
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -buildvcs=false -trimpath -ldflags="-s -w" -o E36731A-LAN-Control.exe .
```

HTML 內嵌於 EXE，修改後需要重建。`ui_test.cjs` 是邏輯替身測試；`browser_test.cjs` 使用 Playwright 與模擬 API 檢查實際瀏覽器流程，絕不連接儀器。後者僅供已具 Playwright／Chromium 的開發機執行，可用 `E36731A_CHROMIUM` 指定瀏覽器路徑、`E36731A_PLAYWRIGHT_MODULE` 指定模組位置；一般 EXE 使用者不需要安裝這些。
